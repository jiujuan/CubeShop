# CS-115 衍修记录：正文编辑器与预览支持富文本（P2 缺陷 #1 配套）

- 任务：CS-115（后台 FAQ 分类与文章管理）
- 关联缺陷：`CS-117/acceptance-CS-117.md` §6 #1
- 日期：2026-09-17

## 背景

缺陷 #1 的修复把用户端改成了「渲染已净化的 HTML」。若后台编辑器仍按「Markdown / 纯文本」标注、
却让作者手写 HTML，会出现「标注与实际不符 + 作者不会写标签」的双重问题；
同时预览弹窗仍是 `whitespace-pre-wrap`，后台无法看到用户端真实效果。

## 修复

| 项 | 改动 |
|----|------|
| 标签口径 | 「正文（Markdown / 纯文本）」→「正文（富文本 HTML）」，并补说明：支持段落/标题/列表/表格/图片/链接；纯文本换行自动保留；保存时后端按白名单净化 |
| 工具条 | 新增 8 个按钮（段落 / 标题 / 加粗 / 斜体 / 列表 / 表格 / 链接 / 图片），`applySnippet()` 在光标处插入；有选中内容则用选中内容作为标签内容，无选中则插入占位文字，插入后光标落到片段末尾 |
| 输入框 | 正文 textarea 改用等宽字体（写标签更易读） |
| 预览 | 预览弹窗改 `v-html` + `.faq-body` 排版样式，与用户端 `FaqDetailView` 保持一致 |

刻意不引入第三方富文本编辑器：净化在白名单侧（后端），编辑器只需降低写标签的成本，
避免为 P2 修复引入一个新的依赖与一套新的样式体系。
