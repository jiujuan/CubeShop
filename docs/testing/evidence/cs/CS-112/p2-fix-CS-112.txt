# CS-112 缺陷 #1 修复记录：FAQ 正文按富文本渲染（P2）

- 任务：CS-112（帮助中心 · 文章详情）
- 关联缺陷：`CS-117/acceptance-CS-117.md` §6 #1（P2 · 展示缺陷）
- 修复日期：2026-09-17
- 结论：**已修复并复验**（后端写入侧白名单净化 + 存量清洗迁移 + 前端 v-html 渲染 + 后台编辑器工具条）

---

## 1. 缺陷回顾

| 项 | 内容 |
|----|------|
| 现象 | 用户端文章详情页正文区直接显示 `<p>一般情况下，付款成功后 48 小时内完成发货（节假日顺延）。</p>` 等原始标签 |
| 根因 | 正文由 Seeder / 后台编辑器存成 HTML 片段（设计文档 §4 要求富文本：图片、表格、锚点），但前端为规避 XSS 用 `whitespace-pre-wrap` 按纯文本渲染 |
| 影响 | 观感与可读性（属「过度安全」的一侧，无安全风险） |

## 2. 修复方向

**净化前移到写入侧**，前端直接渲染已净化内容。理由：正文来源只有后台（受 `cs.faq.manage` 保护），
净化做一次即可；若把净化放在每个渲染端，一旦新增消费方（小程序、邮件模板）就得重复实现一遍。

## 3. 改动清单

| 文件 | 改动 |

## 4. 净化效果样例（实测输出）

| 输入 | 输出 |
|------|------|
| `<p>第一段</p><p>第二段<br>换行</p>` | 原样保留 |
| `<h2 id="faq-1">小节</h2>` | 原样保留（锚点 id 保留） |
| `<table><thead><tr><th colspan="2">表头</th></tr></thead><tbody><tr><td>1</td></tr></tbody></table>` | 原样保留（colspan 保留） |
| `<img src="/storage/a.png" onerror="alert(1)" width="120" alt="图">` | `<img src="/storage/a.png" width="120" alt="图">` |
| `<a href="javascript:alert(1)">点我</a>` | `<a>点我</a>` |
| `<img src="data:text/html;base64,...">` | `<img>` |
| `<p>安全</p><script>alert(1)</script>` | `<p>安全</p>` |
| `<iframe src="//evil.com"></iframe>纯文本` | `纯文本` |
| `<section><font color="red">保留文字</font></section>` | `保留文字` |
| `第一行\n第二行 <b>加粗</b>` | `第一行<br>\n第二行 <b>加粗</b>`（行内片段保留换行） |
| `a < b & c` | `a &lt; b &amp; c`（纯文本转义） |

幂等性：`clean(clean(x)) === clean(x)`（存量清洗可重复执行）。

## 6. 行为变化须知

- 正文不再支持内联样式与自定义 class（净化器刻意不放行 `style`/`class`），排版统一由前端 `.faq-body` 控制；
  历史数据中若有内联样式，已由迁移 000042 一并剥离。
- 纯文本正文自动保留换行（换行转 `<br>`），作者不必手动写 `<br>`。
- 正文中不允许 `<script>`/`<iframe>`/表单元素 —— 这是刻意设计，不是缺陷。
