# CS-117 缺陷 #2（P1）：顶栏 375px 横向溢出 —— 修复前后真浏览器实测

环境：Chromium（agent-browser 驱动），web dev server `http://[::1]:3000`，登录账号 `uibuyer`。
测量方法：`document.documentElement.scrollWidth` 对比 `clientWidth`，并枚举 `body` 下
`getBoundingClientRect().right > innerWidth` 的元素（`clientWidth` 已扣除 15px 纵向滚动条）。

复现脚本：`ui/diag_overflow.sh`（自包含：关闭 → 登录 → 导航 → 设视口 → eval 测量，每步带 `timeout`）。
归档后重跑一致：`{"label":"final-375","scrollW":360,"clientW":360,"overflowCount":7（全部在导航滚动容器内）}`。

## 一、修复前（375×812，/service-center）

```json
{"label":"before-375","path":"/service-center","innerW":375,"scrollW":656,"clientW":360,
 "bodyScrollW":656,"overflowCount":36,"items":[
  "DIV|flex h-10 max-w-xl flex-1 items-center rounded-full border-2 border-[#|203~442",
  "BUTTON|flex h-full w-16 items-center justify-center rounded-r-full bg-[#1677f|376~440",
  "DIV|flex items-center gap-6 text-slate-600|474~626",
  "BUTTON|relative flex flex-col items-center text-xs hover:text-[#1677ff]|474~494"]}
```

**结论**：文档横向溢出 **296px**（656 vs 360）。根因是主头部一行内
logo + 搜索框（`flex-1` 但 `min-width:auto` 无法收缩）+ 右侧入口组总宽超视口，
右侧入口组（购物车 / 我的订单 / 通知 / 用户）整体被推到视口外（右边界 626）。
与验收报告缺陷 #2 的截图现象一致。

## 二、修复后（375×812，/service-center）

```json
{"label":"after-375","path":"/service-center","innerW":375,"scrollW":360,"clientW":360,
 "bodyScrollW":360,"overflowCount":7,"items":[
  "BUTTON|shrink-0 whitespace-nowrap border-b-2 transition-colors|326~382"]}
```

**结论**：文档级横向溢出 **已消除**（`scrollW 360 == clientW 360`）。
剩余 7 个右边界超视口的元素全部位于分类导航的横向滚动容器（`overflow-x-auto`）内，
被容器裁剪、可左右滑动，属预期行为，不产生页面级横向滚动。

## 三、桌面回归（1440×900，/service-center）

```json
{"label":"after-1440","path":"/service-center","innerW":1440,"scrollW":1425,
 "clientW":1425,"overflowCount":0,"items":[]}
```

**结论**：桌面端零溢出，布局与修复前一致（视觉见 `ui/ui-CS-117-desktop-after-service-center.png`）。

## 五、修复手法（`web/src/components/ShopHeader.vue`）

| 位置 | 改动 |
|------|------|
| 公告条 | `px-6`→`px-3 sm:px-6`；文案 `truncate` + 父级 `min-w-0`；账号入口 `hidden sm:flex` |
| 主头部容器 | `gap-8`→`gap-3 lg:gap-8`；`px-6`→`px-3 lg:px-6` |
| logo | `shrink-0`；文字块 `hidden sm:block`；副标语 `hidden lg:block` |
| 搜索框 | 容器加 `min-w-0`（关键：允许 flex 收缩），input 加 `w-full min-w-0`，按钮 `w-16`→`w-11 sm:w-16` |
| 右侧入口组 | `shrink-0`；`gap-6`→`gap-3 lg:gap-6`；购物车/用户名文字 `hidden lg:block`；我的订单 `hidden lg:flex` |
| 分类导航 | `overflow-x-auto` + `lg:overflow-x-visible`；子项 `shrink-0 whitespace-nowrap`（`lg:` 回退 `shrink`/`whitespace-normal` 保持桌面原行为）；分类下拉 `hidden lg:block`（避免被滚动容器裁剪） |

回归锁定：`web/tests/shop-header-responsive.test.ts`（8 例，模板契约断言）。
全量回归：`cd web && npx vitest run` → **18 files / 141 tests passed**。
