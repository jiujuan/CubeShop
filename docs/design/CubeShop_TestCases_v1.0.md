# CubeShop 电商系统
## 测试用例文档（Test Case Document）
**版本**：v1.0（MVP）  
**创建日期**：2026-09-15  
**关联文档**：CubeShop_PRD_v1.0、CubeShop_UseCases_v1.0

---

## 1. 文档说明

### 1.1 目的
本文档基于 CubeShop v1.0 PRD 与用例文档，设计核心功能的测试用例，覆盖正常流程、异常流程与边界场景，作为测试执行与验收的依据。

### 1.2 测试范围
- 用户注册登录与账号相关
- 商品浏览、搜索、详情、加购
- 购物车管理
- 下单、支付、取消、查看订单
- 退款申请与后台处理
- 后台商品/分类/订单管理
- 系统自动超时取消
- 基础安全与异常处理

### 1.3 优先级说明
| 优先级 | 说明 |
|--------|------|
| P0 | 核心交易闭环，必须通过 |
| P1 | 重要功能，影响用户体验或运营 |
| P2 | 次要功能或边界场景 |

### 1.4 用例编号规则
`TC-模块-序号`，例如 TC-USER-001

## 3. 测试执行建议

1. **优先级执行顺序**：先执行所有 P0 用例，确保核心交易闭环通畅，再执行 P1、P2。
2. **数据准备**：准备多规格商品、不同库存状态商品、多种订单状态数据。
3. **支付测试**：优先使用支付渠道沙箱环境，覆盖成功、失败、重复回调场景。
4. **回归重点**：每次发版重点回归 UC-09、UC-10、UC-11、UC-16、UC-19 相关用例。
5. **缺陷记录**：发现问题时记录复现步骤、实际结果、预期结果、环境信息。

---

## 4. 验收通过标准

- 所有 P0 测试用例通过
- P1 用例通过率 ≥ 95%
- 无阻断核心交易流程的缺陷
- 支付回调与库存扣减逻辑正确无异常
- 主要页面在主流浏览器与移动端可正常使用
