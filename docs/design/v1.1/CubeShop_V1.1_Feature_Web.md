## W-F01 商品评价与晒单（P0 · 一期）

### 功能点
- 已完成订单（状态 = completed）的每个商品行项目可评价一次：评分 1~5 星 + 文字 + 最多 9 张图片。
- 评价展示：商品详情页新增「用户评价」区（评分汇总 + 评价列表分页 + 图片预览）。
- 评价标签：默认展示「已购买」标识；后台回复的评价展示商家回复。
- 匿名评价开关（默认昵称脱敏显示，如「张**」）。

### 页面/交互
- `OrderDetailView`：已完成订单的每个行项目出现「评价」按钮 → 评价弹窗/页面。
- `DetailView`：详情页下方新增评价 Tab（好评率、评分分布、列表）。
- 评价成功后不可重复评价，可修改（限 1 次，30 天内）。

### 后端依赖
- 表：`reviews`（见 Backend_Design §2.1）；接口：评价 CRUD + 商品维度评价列表 + 我的评价列表。

### 验收标准
- 仅已完成订单可评价；同一行项目不可重复提交。
- 详情页评价区与汇总数据一致；下架商品历史评价仍可展示。
- 评价含敏感词被拦截时给出明确提示。

### 预估
后端 2.5 天 / 前端 2 天

## W-F02 消息通知中心（P0 · 一期）

### 功能点
- 站内信：顶栏铃铛 + 未读红点 + 通知下拉面板；通知中心页（全部/未读，一键已读）。
- 触发场景（V1.1 首批）：
  | 事件 | 接收方 | 内容要点 |
  |------|--------|----------|
  | 订单支付成功 | 买家 | 订单号、金额 |
  | 订单已发货 | 买家 | 快递公司、单号 |
  | 退款审核结果 | 买家 | 同意/拒绝 + 原因 |
  | 评价收到商家回复 | 买家 | 回复内容 |
  | 低库存预警 | 运营管理员 | 商品/SKU、当前库存 |
- 邮件通道：订单类通知可配置同步发送邮件（异步队列，失败重试 3 次）。

### 页面/交互
- `ShopHeader`：铃铛组件（未读数轮询或登录时拉取）。
- 新页面 `NotificationsView`：列表 + 全部已读 + 单条已读跳转关联订单。

### 后端依赖
- 表：`notifications`（Laravel database 通道可复用，但需自定义站内信结构）；通知 Service + 事件监听（订单状态变更事件挂接）。

### 验收标准
- 支付/发货/退款事件后 1 分钟内站内信可见；邮件失败不影响主流程。
- 未读数准确，点击已读后红点消退。

### 预估
后端 2.5 天 / 前端 1.5 天

## W-F05 商品收藏与浏览足迹（P1 · 一期）

### 功能点
- 收藏：详情页/卡片收藏按钮（红心），收藏列表页（可批量取消、跳转购买）。
- 足迹：浏览详情自动记录（每商品每日一条，最多保留 90 条），足迹页按日期分组。

### 页面/交互
- 新页面 `FavoriteView`、`HistoryView`；个人中心新增两个入口。
- 未登录点击收藏 → 跳登录页，登录后回跳。

### 后端依赖
- 表：`favorites`、`browse_histories`；接口：收藏增删查、足迹记录（详情页曝光时上报）与查询。

### 验收标准
- 收藏状态在卡片/详情间同步；足迹按最新浏览置顶去重。

### 预估
后端 1.5 天 / 前端 1.5 天

## W-F06 优惠券与满减（P0 · 二期，用户端视角）

### 功能点
- 领券中心页：可领券列表（面额、门槛、有效期、剩余量），一键领取。
- 商品/详情页领券入口：展示适用于该商品的券。
- 结算页用券：展示可用券列表（默认最优），选中后金额明细实时更新（商品优惠分摊到行项目）。
- 我的优惠券页：未使用/已使用/已过期三个 Tab。
- 满减活动：商品参与「满 X 减 Y」活动时，详情页与结算页展示活动标签。

### 页面/交互
- 新页面 `CouponCenterView`、`MyCouponsView`；`CheckoutView` 增加用券选择区。
- 用券后金额明细拆分为：商品总额 − 券优惠 − 满减 = 应付 + 运费。

### 后端依赖
- 表：`coupons`、`user_coupons`（见 Backend_Design §2.2）；下单链路改造（用券校验、金额分摊、退款退券）。

### 验收标准
- 券领取限量（总量/每人限领）并发下不超发。
- 用券订单取消/退款时券按规则返还（未使用则返还，且不过期回返）。
- 金额明细任何组合下合计正确（券+满减叠加场景抽样验证）。

### 预估
后端 4 天 / 前端 2.5 天（本版本最高风险项）

## W-F07 物流轨迹查询（P1 · 二期，用户端视角）

### 功能点
- 订单详情（已发货后）展示物流卡片：快递公司、单号、复制按钮、轨迹时间线。
- 无第三方 API 时的降级：仅展示单号 + 官方查询外链。

### 页面/交互
- `OrderDetailView` 新增物流区块，轨迹倒序时间线（最新在前）。

### 后端依赖
- 表：`shipping_traces`；轨迹拉取 Job（对接快递100/快递鸟，定时轮询在途运单）。

### 验收标准
- 发货录入单号后，详情页可见物流卡片；轨迹接口异常时展示降级内容不白屏。

### 预估
后端 2.5 天（含第三方对接）/ 前端 1 天

## W-F08 首页运营位装修（P1 · 二期，用户端视角）

### 功能点
- 首页 Banner 轮播（图、跳转链接、排序、上下线时间）由后台配置。
- 楼层推荐位：后台可选「指定商品 / 指定分类」组成楼层（标题 + 商品网格）。
- 公告栏：首页顶部滚动公告（后台维护）。

### 页面/交互
- `HomeView` 改造：Banner 区、公告区、楼层区数据全部来自配置接口，无配置时保持现有静态兜底布局。

### 后端依赖
- 表：`banners`、`home_floors`、`announcements`；聚合接口 `GET /api/storefront/home-layout`（带缓存）。

### 验收标准
- 后台改配置后首页 5 分钟内生效（缓存失效策略）；图片缺失有占位兜底。

### 预估
后端 2 天 / 前端 2 天

## W-F09 会员积分体系（P2 · 三期，用户端视角）

### 功能点
- 签到得积分（每日 1 次，连续签到递增）；下单得积分（实付 1 元 = 1 分，确认收货后入账）。
- 积分抵扣：结算页可用积分抵现（100 积分 = 1 元，最低抵扣门槛可配置）。
- 积分明细页：获取/消耗流水。

### 后端依赖
- 表：`points`（余额）、`point_logs`、`sign_ins`；结算链路再叠加积分抵扣。

### 验收标准
- 积分获取与抵扣全链路流水可查、可对账；退款按比例回退积分。

### 预估
后端 3 天 / 前端 2 天

## W-F10 搜索引擎增强（P2 · 三期，用户端视角）

### 功能点
- 搜索框关键词联想（拼音首字母匹配）、热搜索词榜。
- 搜索结果相关性排序（标题权重 > 分类 > 描述）、无结果推荐。
- 后端由 LIKE 切换为 Meilisearch（单二进制，Docker Compose 加一个服务）。

### 后端依赖
- Meilisearch 实例 + 商品索引同步（商品上下架/改价时事件同步，每日全量校准兜底）。

### 验收标准
- 万级商品下搜索 P95 < 200ms；上下架商品 1 分钟内从索引增删。

### 预估
后端 3 天 / 前端 1.5 天

## 用户端公共体验优化（随各期顺带完成）
- 骨架屏：列表/详情/订单页加载骨架，替代空白等待。
- 图片懒加载 + WebP（商品图走缩略图参数）。
- 移动端断点复查：购物车/结算/订单页在 375px 宽度下的可用性走查。
- 空态统一组件：收藏/足迹/优惠券/评价等新页面的空态复用分类页「暂无数据」样式。
