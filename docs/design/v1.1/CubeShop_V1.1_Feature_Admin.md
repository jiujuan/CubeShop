# CubeShop V1.1 后台管理端功能详述
**版本**：v1.1（规划稿）
**日期**：2026-09-15
**技术基线**：Vue 3 + TypeScript + Vite + Tailwind + shadcn-vue + Pinia（与 V1.0 一致）
**现状**：后台已有模块 = 登录、仪表盘（概览数字）、商品（分类/商品/SKU）、订单（列表/详情/发货）、退款处理、用户、系统配置、操作日志。

> 功能编号与 [总览](./CubeShop_V1.1_Overview.md) §3 清单对应。

---

## A-F03 数据报表增强（P0 · 一期）

### 功能点
- **仪表盘改版**：
  - 核心指标卡扩展：今日/昨日/近 7 日订单量、销售额、客单价、支付转化率（支付单/下单）。
  - 销售趋势图：近 30 日订单量 + 销售额双轴折线（ECharts）。
  - 商品销量 TOP10 / 分类销售占比饼图。
  - 待办聚合：待发货、待退款、库存预警数量直达对应列表。
- **报表中心页**（新菜单「数据报表」）：
  - 按日期区间查询：销售额/订单量明细表 + 导出 Excel。
  - 用户维度：新增注册数趋势、复购率（有 ≥2 笔完成订单的用户占比）。
- 权限码：`report.view`。

### 页面
- `dashboard` 改版；新增 `report` 目录（报表中心页）。

### 后端依赖
- 报表查询接口（基于 orders/order_items/payments 聚合 SQL，日粒度汇总表 `report_daily_stats` 可选优化项，数据量大后再引入）。

### 验收标准
- 报表数据与订单真实数据抽样核对一致（含退款单剔除口径明确）。
- 趋势图区间可选（7/30/90 天），导出文件字段与页面一致。

### 预估
后端 2 天 / 前端 2.5 天

## A-F04 管理员账号与角色管理（P0 · 一期）

### 功能点
- **管理员账号管理**：后台账号列表（新增/编辑/禁用/重置密码），分配角色。
- **角色管理**：角色列表 + 新建角色，角色勾选权限码（树形展示 13 个现有权限码 + V1.1 新增码）。
- **操作日志增强**：日志列表支持按操作人、模块、时间区间筛选（V1.0 仅查询）。
- 超管专属菜单；运营角色不可见「系统管理」分组。

### 页面
- `system` 目录新增：`AccountListView`、`RoleListView`（含权限分配抽屉）。

### 后端依赖
- 基于现有 spatie/permission 新增管理接口（账号 CRUD 绑定 model_has_roles；角色权限同步 role_has_permissions）。
- 新权限码：`account.manage`、`role.manage`（种子数据同步更新）。

### 验收标准
- 新建角色仅勾选部分权限后，该角色登录后台仅见对应菜单与按钮（v-permission 生效）。
- 被禁用账号立即无法访问（Token 校验时校验账号状态）。
- 所有账号/角色变更写入操作日志。

### 预估
后端 2 天 / 前端 2 天

## A-F01 营销管理（P0 · 二期，后台视角）

### 功能点
- **优惠券管理**：
  - 创建券：名称、类型（满减券/折扣券）、面额/折扣、使用门槛、有效期（绝对/领取后 N 天）、发放总量、每人限领、适用商品范围（全部/指定分类/指定商品）。
  - 列表：发放量/领取量/核销量统计，手动停止发放。
- **满减活动管理**：活动名称、门槛梯度（满 X 减 Y 多级）、参与商品、活动时间、启停。
- **领券数据**：券维度领取/使用明细导出。

### 页面
- 新菜单「营销管理」：`CouponListView`（含创建表单）、`PromotionListView`。

### 后端依赖
- 表 `coupons` / `user_coupons` / `promotions`；发券走库存式扣减（Redis 或 `UPDATE ... WHERE issued < total` 条件更新防超发）。

### 验收标准
- 创建的券在用户端领券中心实时可见/可领；停发后立即不可领。
- 核销量与用户端用券记录对得上。

### 预估
后端 2.5 天 / 前端 2.5 天（与用户端 F06 合计计入二期）

## A-F02 评价管理（P0 · 一期，后台视角）

### 功能点
- 评价列表：按商品/评分/状态筛选，查看评价详情与图片。
- 审核模式：可配置「先审后显」（system_configs 加开关）；待审核队列一键通过/驳回（驳回填原因）。
- 商家回复：对任意评价回复一条（前台展示）；删除恶意评价（记录操作日志）。

### 页面
- 新菜单「评价管理」：`ReviewListView`。

### 后端依赖
- 评价状态机（pending → approved / rejected）；权限码 `review.manage`。

### 验收标准
- 开启先审后显后，新评价未审核不在前台出现。
- 回复/删除操作后前台 5 分钟内同步（缓存刷新）。

### 预估
后端 1 天 / 前端 1.5 天

## A-F07 物流发货增强（P1 · 二期，后台视角）

### 功能点
- 发货表单升级：选择快递公司（内置常用字典）+ 录入运单号，支持批量发货（Excel 导入单号）。
- 在途运单轨迹自动拉取状态展示（成功/失败/待拉取），失败的标记并支持手动重试。
- 常用快递公司字典可维护。

### 页面
- `order` 目录：发货弹窗改造、批量发货入口；新增 `ShippingTraceView`（可选，聚合异常运单）。

### 后端依赖
- 表 `shippings`（V1.0 发货信息落库扩展）+ `shipping_traces`；轨迹轮询 Command（每 30 分钟，仅拉取在途单）。

### 验收标准
- 批量发货 100 单内 1 分钟完成；单号错误有即时校验反馈。

### 预估
后端 2 天 / 前端 1.5 天

## A-F08 首页装修管理（P1 · 二期，后台视角）

### 功能点
- Banner 管理：上传图、跳转链接（支持商品/分类/自定义 URL）、排序、上下线时间、启停。
- 楼层管理：创建楼层（标题、类型=指定商品/指定分类、选择商品或分类、排序）。
- 公告管理：发布/撤下公告，生效时间。

### 页面
- 新菜单「内容管理」：`BannerListView`、`FloorListView`、`AnnouncementListView`。

### 后端依赖
- 表 `banners` / `home_floors` / `announcements`；首页布局聚合接口写缓存，后台变更主动失效。

### 验收标准
- 所有配置变更 5 分钟内在前台生效；停用的 Banner 立即不可见。

### 预估
后端 1.5 天 / 前端 2 天

## A-F11 商品批量导入（P2 · 三期）

### 功能点
- Excel 模板下载（字段：分类、标题、主图 URL、SKU 规格/价格/库存等）。
- 上传导入：逐行校验，返回校验结果（成功 N 条 / 失败明细，可下载失败清单修正后重传）。
- 导入为「下架」状态，人工确认后手动上架，防脏数据直接进前台。

### 后端依赖
- 队列 Job 异步解析导入（复用 V1.0 导出用的 Excel 能力，如 maatwebsite/excel 或 openspout）。

### 验收标准
- 500 行导入 2 分钟内完成；失败行不影响成功行；全部写入操作日志。

### 预估
后端 2.5 天 / 前端 1 天

|----------|------|
